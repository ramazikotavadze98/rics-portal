RICS Study Access

Sign in to keep progress separate for each learner.

Admin panel supports progress review for all users.

Admins can sign in with private credentials.

Username must be 3-32 characters, using only lowercase letters, numbers, dot, underscore, or hyphen.
Any email provider accepted (Gmail, Hotmail, Yahoo, etc.)
Enter a valid mobile number with country code (e.g., +995 555 123 456).
Password must be at least 6 characters.
Enter your username, email (any provider), or phone number associated with your account.
Reset code is sent to your registered email or phone. For local testing, the code is printed in server terminal logs.
